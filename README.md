Leonida Platinum — an offline guide and tracker for all 55 GTA 6 trophies on PlayStation 5: every official name, description and grade, a checklist saved in the browser with export and import, a Next up planner that puts the missable trophies first, then your current roadmap stage, then the rest in stage order (ticking one off moves the plan on), per-stage progress on the 5-stage roadmap to the platinum, filters by kind (story, missable, collectibles, activities, online) and a spoiler setting that hides story trophies until earned, 7 missable trophies flagged, and a guide in our own words for every trophy that cites its sources (Exophase and PSNProfiles). Static files only — no build step, no network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To hand the entry in, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
